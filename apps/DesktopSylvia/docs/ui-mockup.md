## コンポーネント構成

### 1. Sidebar（左端）
- **幅**: 56px（固定）
- **役割**: アプリ内ナビゲーション
- **要素**:
  - 🏠 ダッシュボードボタン（上部）
  - ⚙️ 設定ボタン（下部）

### 2. Dashboard（左ペイン）
- **幅**: 320-400px（可変）
- **役割**: 情報の一覧表示
- **セクション**:
  - **今日のタスク**: ステータス絵文字 + タイトル + 担当者
  - **予定**: 時刻 + タイトル（カレンダー連携用）
  - **通知**: 未読バッジ + メッセージ + 時刻
  - **Todo**: チェックボックス + タスク

### 3. Chat（右ペイン）
- **幅**: 残り全幅
- **役割**: AIとのコミュニケーション
- **要素**:
  - **ヘッダー**: タイトル + 接続状態
  - **メッセージエリア**: 会話履歴（ユーザー/アシスタント）
  - **入力エリア**: テキスト入力 + 送信ボタン
