## 1. 概要

### 1.1 残留リソース

VSCode拡張機能をアンインストールしても、以下のリソースは自動削除されません:

| リソース | 場所 | サイズ目安 |
|---------|------|-----------|
| グローバル設定 | `~/.maid-agent/` | 50-150MB |
| プロジェクト設定 | `{project}/.maid-agent/` | 可変 |
| tmuxセッション | `maid-agent-*` | - |
| VSCode設定 | `settings.json` 内 | - |

### 1.2 クリーンアップレベル

| レベル | 説明 | 推奨ケース |
|--------|------|-----------|
| 最小限 | tmuxセッション終了 + 拡張アンインストールのみ | 再インストール予定あり |
| 標準 | 上記 + グローバル設定削除 | 完全削除したい |
| 完全 | 上記 + プロジェクト設定削除 + VSCode設定リセット | 痕跡を残さない |

## 2. アンインストール前の準備

### 2.1 作業中のタスク確認

実行中のタスクがある場合、先に完了させるか中断してください。

```bash
# タスク状態を確認（プロジェクトディレクトリで実行）
cat .maid-agent/system/data/tasks.yaml | grep -A5 "status:"
```

### 2.2 保存すべきデータの確認

以下のデータは削除前にバックアップを検討してください:

| データ | 場所 | 内容 |
|--------|------|------|
| ご主人様メモ | `.maid-agent/master/NOTES.md` | 個人メモ |
| 作業報告書 | `.maid-agent/master/reports/` | 過去の作業報告 |
| タスク履歴 | `.maid-agent/system/data/tasks.yaml` | 作業履歴 |
| カスタムルール | `~/.maid-agent/rules/` | ユーザー定義ルール |
| カスタムスキル | `~/.maid-agent/skills/` | ユーザー定義スキル |

バックアップ例:

```bash
# プロジェクト設定のバックアップ
cp -r .maid-agent/master ~/maid-agent-backup/

# グローバル設定のバックアップ
cp -r ~/.maid-agent/rules ~/maid-agent-backup/
cp -r ~/.maid-agent/skills ~/maid-agent-backup/
```

## 3. tmuxセッションの終了

### 3.1 セッション確認

```bash
# Maid-Agent関連のセッション一覧
tmux list-sessions 2>/dev/null | grep maid-agent
```

出力例:
```
maid-agent-maidshouse-btx9: 10 windows (created ...)
```

### 3.2 セッション終了

**方法A: 個別に終了**

```bash
# セッション名を指定して終了
tmux kill-session -t maid-agent-maidshouse-btx9
```

**方法B: 一括終了**

```bash
# 全てのMaid-Agentセッションを終了
tmux list-sessions 2>/dev/null | grep maid-agent | cut -d: -f1 | xargs -I{} tmux kill-session -t {}
```

### 3.3 終了確認

```bash
# セッションがないことを確認
tmux list-sessions 2>/dev/null | grep maid-agent
# (出力なし = 正常)
```

## 4. VSCode拡張機能のアンインストール

### 4.1 VSCodeからアンインストール

1. VSCodeを開く
2. 拡張機能パネルを開く（`Ctrl+Shift+X` / `Cmd+Shift+X`）
3. 「Maid Agent」を検索
4. **アンインストール** をクリック
5. VSCodeを再起動

### 4.2 コマンドラインからアンインストール

```bash
code --uninstall-extension your-publisher.maid-agent
```

## 5. グローバル設定の削除

### 5.1 削除対象

| パス | 内容 | サイズ |
|------|------|--------|
| `~/.maid-agent/maid-agent-messenger/` | MCPサーバー本体 | 50-100MB |
| `~/.maid-agent/rules/` | グローバルルール | 小 |
| `~/.maid-agent/skills/` | グローバルスキル | 小 |
| `~/.maid-agent/system/` | システム設定 | 小 |

### 5.2 削除コマンド

**標準削除（全て）**:

```bash
rm -rf ~/.maid-agent/
```

**選択的削除**:

```bash
# MCPサーバーのみ削除（大容量部分）
rm -rf ~/.maid-agent/maid-agent-messenger/

# ログのみ削除
rm -rf ~/.maid-agent/maid-agent-messenger/logs/
```

### 5.3 削除確認

```bash
# ディレクトリが存在しないことを確認
ls ~/.maid-agent/ 2>/dev/null || echo "削除完了"
```

## 6. プロジェクト設定の削除（オプション）

### 6.1 削除対象

| パス | 内容 | 削除推奨度 |
|------|------|-----------|
| `.maid-agent/system/data/maid/` | メイド状態（一時） | 高 |
| `.maid-agent/system/data/reports/` | 現在の報告書（一時） | 高 |
| `.maid-agent/system/data/notifications/` | 通知キュー（一時） | 高 |
| `.maid-agent/system/config/.session-name` | セッション名（一時） | 高 |
| `.maid-agent/master/` | ご主人様データ | 確認後 |
| `.maid-agent/agents/` | エージェント設定 | 確認後 |
| `.maid-agent/system/data/tasks.yaml` | タスク履歴 | 確認後 |
| `.maid-agent/CLAUDE.md` | プロジェクト指示書 | Git管理確認 |

### 6.2 一時ファイルのみ削除

```bash
cd /path/to/project

# 一時ファイルの削除（データは残す）
rm -rf .maid-agent/system/data/maid/
rm -rf .maid-agent/system/data/reports/
rm -rf .maid-agent/system/data/notifications/
rm -f .maid-agent/system/config/.session-name
```

### 6.3 完全削除

```bash
cd /path/to/project

# プロジェクト設定を完全削除
rm -rf .maid-agent/
```

### 6.4 Git管理下の場合

`.maid-agent/` がGit管理されている場合:

```bash
# 追跡されていないファイルのみ削除
git clean -fd .maid-agent/

# .gitignore対象も含めて削除
git clean -fdx .maid-agent/
```

## 7. VSCode設定のリセット（オプション）

### 7.1 対象設定

以下の設定が `settings.json` に追加されている可能性があります:

```json
{
  "maidAgent.maidOrder": ["emma", "sophia", "lily", "rose", "alice", "may", "flora", "luna"],
  "maidAgent.showAgentPanel": true,
  "maidAgent.sessionWarningThreshold": 10,
  "maidAgent.autoResumeOnStartup": true
}
```

### 7.2 設定の削除

1. VSCodeで `Ctrl+,`（設定を開く）
2. 右上の「設定（JSON）を開く」アイコンをクリック
3. `maidAgent` で始まる設定を検索して削除
4. 保存

または、コマンドラインで:

```bash
# settings.jsonの場所（Linuxの場合）
code ~/.config/Code/User/settings.json

# macOSの場合
code ~/Library/Application\ Support/Code/User/settings.json

# WSLの場合
code /mnt/c/Users/{username}/AppData/Roaming/Code/User/settings.json
```

## 8. 削除確認

### 8.1 確認チェックリスト

| 項目 | 確認コマンド | 期待結果 |
|------|-------------|---------|
| tmuxセッション | `tmux list-sessions \| grep maid-agent` | 出力なし |
| グローバル設定 | `ls ~/.maid-agent/` | エラー（存在しない） |
| プロジェクト設定 | `ls .maid-agent/` | エラー（存在しない） |
| VSCode拡張 | `code --list-extensions \| grep maid` | 出力なし |

### 8.2 一括確認スクリプト

```bash
#!/bin/bash
echo "=== Maid-Agent 削除確認 ==="

echo -n "tmuxセッション: "
if tmux list-sessions 2>/dev/null | grep -q maid-agent; then
  echo "残存あり"
else
  echo "OK"
fi

echo -n "グローバル設定: "
if [ -d ~/.maid-agent ]; then
  echo "残存あり (~/.maid-agent/)"
else
  echo "OK"
fi

echo -n "VSCode拡張: "
if code --list-extensions 2>/dev/null | grep -qi maid; then
  echo "インストール済み"
else
  echo "OK"
fi

echo "=== 確認完了 ==="
```

## 付録: クイックリファレンス

### 完全削除コマンド（一括実行）

```bash
# 1. tmuxセッション終了
tmux list-sessions 2>/dev/null | grep maid-agent | cut -d: -f1 | xargs -I{} tmux kill-session -t {}

# 2. グローバル設定削除
rm -rf ~/.maid-agent/

# 3. プロジェクト設定削除（必要な場合）
# cd /path/to/project && rm -rf .maid-agent/
```

### 再インストールする場合

再インストール時、グローバル設定は自動で再作成されます。プロジェクト設定は `Maid Agent: Initialize` コマンドで再初期化できます。
