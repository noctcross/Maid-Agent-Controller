# Blocked Handling - ブロック時の対応フロー

## 概要

外部要因で作業を進められない場合の対応手順。
エスカレーション要否を判断し、適切なフローで報告する。

## 適用条件

- 技術的な問題で作業が進められない
- ご主人様の判断が必要な事項が発生
- 依存タスクの完了待ち
- リソース（ファイル、環境等）へのアクセス問題

## 判断基準

| 状況 | --escalation | フロー |
|------|-------------|--------|
| ご主人様の判断が必要（技術方針・ライセンス・重要決定等） | あり | フロー1 |
| メイド長で解決可能（依存タスク待ち・リソース調整等） | なし | フロー2 |

### ご主人様判断が必要なケース

- 技術的な重要決定（アーキテクチャ選択、破壊的変更等）
- ライセンス・著作権に関する判断
- 方針・優先順位の決定
- 外部サービスの契約・設定変更

### メイド長で解決可能なケース

- 依存タスクの完了待ち
- 他メイドへの相談・協力依頼
- リソース調整（ファイル競合等）
- 不明点の確認

## フロー1: ご主人様判断が必要な場合

### 1. 報告書に詳細を記載

```markdown
## 問題・注意点
{問題の詳細説明}

## エスカレーション
escalation:
  required: true
  title: "{エスカレーション件名}"
  detail: "{詳細な説明、判断に必要な情報}"
```

### 2. ステータスを blocked に更新

```bash
maidctl my-status blocked --summary "{エスカレーション件名}" --escalation
```

### 3. メイド長に通知

```bash
maidctl notify chief "{件名}でブロックされました。ご主人様のご判断が必要です。"
```

## フロー2: メイド長で解決可能な場合

### 1. 報告書に詳細を記載

```markdown
## 問題・注意点
{ブロック理由の説明}
```

### 2. ステータスを blocked に更新

```bash
maidctl my-status blocked --summary "{ブロック理由}"
# --escalation は省略（デフォルト false）
```

### 3. メイド長に通知

```bash
maidctl notify chief "ブロックされました。{ブロック理由}。"
```

## --escalation パラメータの役割

| 要素 | 役割 |
|------|------|
| `--escalation` フラグ | メイド長への構造化シグナル（機械的に検知可能） |
| 報告書の `escalation` セクション | 詳細情報（なぜ必要かの背景） |

**両者は補完関係。片方だけでは不十分。**

## 他メイドへの相談依頼

他のメイドに意見を求めたい、協力が必要な場合は、**メイド長にエスカレーション**します。

```
あなた（メイド）
    ↓ maidctl notify で依頼
メイド長
    ├─ 追加タスクとして他メイドに割り振り（create_task）
    └─ または、🚨 要対応タスクとしてご主人様に報告
```

### 相談依頼の例

```bash
# 他メイドへの相談を依頼
maidctl notify chief "ソフィアさんへの相談依頼: APIの設計について意見をいただきたいです。詳細は報告書に記載しました。"
```

## 注意点

- **直接連絡は禁止** - 必ずメイド長経由
- **報告書に詳細を記載** - 通知だけでは情報不足
- **ブロック後は停止** - 次の指示を待つ（ポーリング禁止）

## 事例

### 事例1: ライセンス確認が必要

```bash
# 報告書に記載
## エスカレーション
escalation:
  required: true
  title: "MITライセンスライブラリの使用可否確認"
  detail: "依存ライブラリにMITライセンスのものが含まれています。プロジェクトでの使用可否をご確認ください。"

# コマンド実行
maidctl my-status blocked --summary "ライセンス確認待ち" --escalation
maidctl notify chief "MITライセンスライブラリの使用可否確認でブロックされました。ご主人様のご判断が必要です。"
```

### 事例2: 依存タスク待ち

```bash
# 報告書に記載
## 問題・注意点
task-001-2（APIエンドポイント実装）の完了を待っています。

# コマンド実行
maidctl my-status blocked --summary "task-001-2 完了待ち"
maidctl notify chief "依存タスク task-001-2 の完了待ちでブロックされました。"
```
