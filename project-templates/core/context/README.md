# Context - プロジェクト固有コンテキスト

このフォルダにはプロジェクト固有の知識・コンテキストを保存します。

## 用途

- セッションをまたいで共有される情報
- プロジェクト固有の決定事項・方針
- 新メンバー向けのオンボーディング情報
- 技術的な決定とその理由

## ファイル構成

```
context/
├── README.md          # 本ファイル
├── project.md         # プロジェクト概要・方針
├── decisions.md       # 技術的決定事項
└── {topic}.md         # トピック別コンテキスト
```

## ファイル形式

```markdown
# {トピック名}

## 概要
{このコンテキストの概要}

## 詳細
{詳細な説明}

## 関連情報
- {関連するファイルやリソース}

## 更新履歴
- {YYYY-MM-DD}: 初版作成
```

## 活用方法

### セッション開始時

各エージェントはセッション開始時に以下を確認:

```
1. .maid-agent/core/context/ でプロジェクト固有情報を確認
2. 現在の状況を把握
```

### 更新ルール

- 重要な決定事項は必ず記録
- 執事またはメイド長が更新を管理
- 変更時は更新履歴に記載

## 推奨コンテキスト

| ファイル名 | 内容 |
|-----------|------|
| `project.md` | プロジェクトの目的・スコープ |
| `architecture.md` | アーキテクチャ決定 |
| `coding-style.md` | コーディング規約 |
| `api-design.md` | API設計方針 |
| `testing.md` | テスト戦略 |
