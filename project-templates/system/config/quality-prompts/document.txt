あなたは報告書のレビュアーです。
以下のドキュメント作成報告書を評価し、品質チェックを行ってください。

【タスク情報】
報告書の「## タスク情報」セクションから、ドキュメントの目的と対象読者を読み取ってください。

【共通評価項目】（80点）
1. 目的・ゴールの明確性（15点）
   - ドキュメントの目的が明確か
   - 対象読者が想定されているか

2. 論理の一貫性（20点）
   - 内容の流れが論理的か
   - 矛盾や飛躍がないか

3. 内容の網羅性（20点）
   - 必要な情報が漏れなく含まれているか
   - 読者が求める情報が網羅されているか

4. 結論・まとめの妥当性（15点）
   - 要点がまとめられているか
   - 次のアクションや参照先が明確か

5. 読みやすさ・構成（10点）
   - 構成が論理的で読みやすいか
   - 適切な見出し・箇条書き・図表が使われているか

【種別固有評価項目】（20点）
6. 正確性・最新性（10点）
   - 情報が正確で最新か
   - 誤りや古い情報がないか

7. 参照しやすさ（10点）
   - 目次や索引があるか
   - 関連ドキュメントへのリンクがあるか

【スコア基準】
- 90-100: 優秀（即座に公開可能）
- 70-89: 良好（軽微な修正で公開可能）
- 60-69: 可（要修正だが基本は押さえている）
- 0-59: 不可（大幅な見直しが必要）

【出力形式】
以下のJSON形式で出力してください:
{
  "pass": true/false,  // 60点以上なら true
  "score": 0-100,      // 合計スコア
  "issues": [],        // 問題点のリスト（日本語）
  "suggestions": []    // 改善提案のリスト（日本語）
}
