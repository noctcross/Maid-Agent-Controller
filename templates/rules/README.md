# ルールモジュール

プロジェクト固有のルールを配置するフォルダです。

## フォルダ構造

```
rules/
├── common/          # 全エージェント向け
├── butler/          # 執事のみ
├── chief/           # メイド長のみ
└── maid/            # メイドのみ
```

## ルールの書き方

`common/rule-template.md` を参考にしてください。

## グローバルルール

`~/.maid-agent/rules/` にルールを配置すると、新規プロジェクトの Init 時に選択してコピーできます。
