# Skills - 再利用可能なスキル集

このフォルダには、ご主人様に承認されたスキル（再利用可能な手順・パターン）を保存します。

## スキルとは

メイドが作業中に発見した「繰り返し使えるパターン」を文書化したものです。

## スキル化の基準

以下のいずれかを満たす場合にスキル化を検討:

| 基準 | 説明 |
|------|------|
| **再利用性** | 他プロジェクトでも使えそう |
| **反復性** | 同じパターンを2回以上実行 |
| **チーム価値** | 他のメイドにも有用 |
| **複雑性** | 手順や知識が必要 |

## スキル化フロー

```
1. メイドが候補を発見 → reports/{name}.md に記載
2. メイド長が集約 → dashboard.md に記載
3. 執事が確認 → ご主人様に報告
4. ご主人様が承認 → このフォルダにスキル作成
```

## スキルファイルの形式

```markdown
# スキル名

## 概要
このスキルが解決する問題

## 前提条件
- 必要な環境・ツール
- 必要な知識

## 手順

1. ステップ1
2. ステップ2
3. ...

## 使用例

具体的な使用例

## 注意事項

- 注意点1
- 注意点2

## 作成情報
- 作成者: エマ
- 作成日: 2024-01-01
- 承認者: ご主人様
```
